# Dépendances

Versions directes résolues le 25 juillet 2026. `pnpm-lock.yaml` demeure la source de vérité pour l’ensemble de l’arbre transitif.

| `astro`                       | `7.1.3`   | Production    | Génération statique, routage et compilation.     | `astro.config.mjs`, scripts, fichiers `.astro`.   | Cœur de l’architecture imposée. | `@astrojs/react`              | `6.0.1`   | Production    | Rendu et hydratation des composants React.       | `astro.config.mjs`.                               | Intégration officielle. | `react-dom`                   | `19.2.8`  | Production    | Hydratation React dans le navigateur.            | Utilisé par l’intégration Astro React.            | Pair officiel de React. ## Paquets volontairement absents

`@astrojs/sitemap` sera ajouté seulement lorsqu’une URL canonique sera connue. React Router, CMS, bibliothèques UI, animations, formulaires, validation, dates, tests E2E, backend, ORM et base de données sont hors périmètre.

Vitest et Playwright seront évalués quand des composants interactifs réels et des parcours critiques auront été développés.
