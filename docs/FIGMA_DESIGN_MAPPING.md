# Cartographie du design Figma vers Astro

Audit réalisé le 25 juillet 2026 avant l’implémentation du ticket S1-T01. L’export sous `reference/figma-make-export/` demeure intact et constitue la source de vérité visuelle. Les valeurs du prototype exécutable priment sur les intentions générales du brief lorsqu’elles sont explicites.

## Sources inspectées

- `src/index.css` pour les polices, couleurs et espacements globaux;
- `src/App.tsx` pour le header, la navigation, le menu mobile, le footer et les interactions;
- `src/pages/Home.tsx`, `NotreParoisse.tsx`, `Horaires.tsx`, `PremiereVisite.tsx` et `Contact.tsx` pour les hiérarchies et layouts représentatifs;
- `src/imports/pasted_text/paroisse-website-mockups.md` pour la grille, les tailles cibles et l’intention éditoriale;
- `.figma/make/site.json`, `vite.config.ts`, `package.json`, `AGENTS.md` et `CLAUDE.md` pour le contexte technique.

Les chemins de ce document sont relatifs à `reference/figma-make-export/`.

## Breakpoints de validation

| Référence          | Comportement cible                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| 360, 390 et 430 px | Header 64 px, menu mobile, gutter 20 px, footer une colonne, actions rapides.                    |
| 768 px             | Header 80 px, menu mobile, gutter 40 px, footer deux colonnes.                                   |
| 1024 px            | Grilles de contenu desktop lorsque pertinent, mais navigation mobile pour éviter le débordement. |
| 1280 px            | Header desktop complet; aucune collision entre identité et navigation.                           |
| 1440 px            | Header desktop, footer quatre colonnes, gutter 80 px, conteneur maximal 1280 px.                 |

## Divergences volontaires et corrections

1. La palette premium documentée remplace les valeurs beige originales sans modifier leurs rôles.
2. Le header desktop commence à 1280 px plutôt qu’à 1024 px pour empêcher le
   débordement, seuil rendu possible par la suppression du CTA Horaires.
3. Le doré n’est pas utilisé comme petit texte sur ivoire lorsqu’il échoue au contraste AA; un texte bourgogne ou charbon conserve la hiérarchie, avec le doré en filet ou motif.
4. Les textes du footer passent d’une opacité ivoire de 30 % à au moins 60 % lorsqu’ils transmettent une information.
5. Les contrôles principaux atteignent 48 × 48 px.
6. Le menu mobile ajoute Escape, focus initial, piège de focus, retour du focus, `inert`, verrouillage du fond et défilement interne.
7. Le skip link, `aria-current`, les noms de navigation et `prefers-reduced-motion` sont ajoutés.
8. Les placeholders inconnus ne produisent pas de liens `tel:`, `mailto:` ou sociaux invalides.
9. Un scrim charbon de 10 % et des liens ivoire pleins sécurisent le contraste du header transparent sur les zones photographiques claires.

Ces différences ne changent ni la composition, ni les proportions éditoriales, ni l’ambiance du prototype.
